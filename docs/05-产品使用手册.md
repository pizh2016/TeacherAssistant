## 一、系统概述

"喊话小喇叭"是一套校园实时通知系统，适用于学校跨教室、跨楼层的即时通知场景。系统由三部分组成：

| 组件 | 形态 | 部署位置 | 用途 |
|------|------|----------|------|
| **后端服务** | Python 程序（内嵌运行环境） | 办公室电脑 | 消息存储、实时消息推送、认证管理、定时调度 |
| **教师端 H5** | 浏览器访问的网页 | 办公室电脑浏览器 | 教师编辑并发送通知消息 |
| **大屏端** | Windows 桌面应用（Electron） | 各教室电脑 | 教室大屏实时展示消息 + 语音播报 |

**部署拓扑**：

```
┌──────────────────────────────────────┐
│        办公室电脑（后端服务）          │
│  后端服务  端口: 18800                │
│  教师端 H5 静态托管 + 管理后台        │
│  SQLite 数据库                       │
└──────────────┬───────────────────────┘
               │ 局域网交换机
         ┌─────┼─────┐
         │     │     │
      ┌──┴─┐┌──┴─┐┌──┴─┐
      │教室1││教室2││教室3│
      │大屏端││大屏端││大屏端│
      └────┘└────┘└────┘
```

**核心流程**：

```
教师在办公室电脑浏览器输入文字 → 点击发送 → 教室大屏 2 秒内弹出显示 → 同时语音播报
```

## 二、系统安装与部署

### 2.1 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 及以上（64 位） |
| 网络 | 局域网（办公室电脑与各教室电脑互通） |
| 浏览器 | Chrome / Edge 最新版（教师端 + 管理后台） |
| 防火墙 | 放行 TCP 端口 18800 |

### 2.2 部署后端服务（办公室电脑）

后端服务部署在办公室电脑上，负责数据存储、消息广播和页面托管。

**部署步骤**：

1. 将后端发布包（`Classroom-Horn-v0.2.0-win-x64.zip`）解压到目标目录，如 `C:\ClassroomHorn\`
2. 配置防火墙放行 18800 端口：
   ```cmd
   netsh advfirewall firewall add rule name="Classroom Horn" dir=in action=allow protocol=TCP localport=18800
   ```
3. 双击 `start-backend.bat` 启动后端服务
4. 验证服务正常：在浏览器中访问 `http://localhost:18800/health`，应返回 JSON 状态信息

> **提示**：后端服务需保持运行状态。建议将 `start-backend.bat` 的快捷方式放入“启动”文件夹（`Win+R` → `shell:startup`），实现开机自启。

### 2.3 访问教师端

教师端是纯网页应用，无需安装任何软件。在办公室电脑浏览器中打开以下地址：

```
http://<办公室电脑IP>:18800/static/teacher/
```

例如，办公室电脑 IP 为 `192.168.5.153`，则访问：

```
http://192.168.5.153:18800/static/teacher/
```

> **提示**：IP 地址请向学校 IT 管理员确认。如果教师端和后端在同一台电脑上，也可以使用 `http://localhost:18800/static/teacher/`。

### 2.4 访问管理后台

管理后台同样是网页应用，在浏览器中打开：

```
http://<办公室电脑IP>:18800/static/admin/
```

### 2.5 网络与端口说明

| 端口 | 协议 | 用途 |
|------|------|------|
| **18800** | HTTP | 接口服务 + 教师端/管理后台静态页面托管 |
| **18800** | WebSocket | 大屏端实时消息推送 |

**跨网段部署注意**：如果办公室电脑和教室电脑不在同一网段（如办公室在 `192.168.5.x`，教室在 `192.168.40.x`），需确保：

1. 后端监听地址为 `0.0.0.0`（默认已配置）
2. 各网段之间的路由/防火墙允许 TCP 18800 端口通信
3. 办公室电脑的 Windows 防火墙已放行 18800 端口

## 三、教师端使用指南

### 3.1 如何访问教师端

教师端是纯网页应用，无需安装任何软件，在办公室电脑浏览器中直接访问即可。

**访问地址**：

```
http://<办公室电脑IP>:18800/static/teacher/
```

> **提示**：IP 地址请向学校 IT 管理员确认。如果教师端和后端在同一台电脑上，也可以使用 `http://localhost:18800/static/teacher/`。

### 3.2 教师姓名登录

当前版本教师端采用**姓名登录**，无需记忆密码：

1. 打开教师端页面，看到登录界面
2. 在"姓名"输入框中，输入您的姓名（如"王老师"）
3. 点击"登录"按钮
4. **首次登录**：系统自动为您创建教师账户，进入主页面
5. **再次登录**：系统自动识别您的身份，恢复您的班级和模板数据

> **提示**：姓名即账号，请牢记您使用的姓名。如需更换姓名，需重新登录。

### 3.3 选择班级

登录成功后，主页面顶部显示您所管理的班级列表：

- 默认选中第一个班级
- 点击班级名称即可切换目标班级
- 支持管理多个班级（如同时带 A 班和 B 班）
- **批量模式**：点击"批量"开关可进入多选模式，同时选择最多 6 个班级发送消息

### 3.4 编辑与发送消息

**操作步骤**：

1. **使用自定义模板**（推荐）：输入框上方显示您在「模板管理」中保存的常用语，点击即可快速填入
2. **输入内容**：在文本框中输入通知内容（最多 500 字）
3. **附加图片**（可选）：点击"上传图片"按钮，选择一张图片（≤5MB，支持 JPG/PNG/GIF/WebP），图片将随消息一起展示在大屏上
4. **选择目标班级**：
   - **单班模式**（默认）：选择一个班级发送
   - **批量模式**：开启批量开关后，可勾选多个班级（最多 6 个），同时发送
5. **选择展示方式**：
   - **弹窗**（默认）：大屏中央全屏弹出，适合重要通知
   - **跑马灯**：屏幕顶部横向滚动，适合简短提醒
6. **选择提醒强度**：
   - **普通**（默认）：正常弹窗显示
   - **强提醒**：红色边框闪烁 + 醒目样式，用于紧急通知
7. **语音播报**：默认开启，大屏端会自动朗读消息内容
8. **显示时长**：选择消息在大屏上停留的时间（30 秒 ~ 5 分钟）
9. 点击 **"立即发送"** 按钮

发送成功后会显示绿色提示"发送成功！"，消息将在 2 秒内出现在目标班级的大屏上。

### 3.5 撤回消息

发送后 **60 秒内**可以撤回消息：

1. 在历史记录中找到刚发送的消息
2. 点击 **"撤回"** 按钮
3. 确认后，消息将从所有目标班级的大屏上立即消失

> **注意**：超过 60 秒后撤回按钮将不可用。

### 3.6 查看历史记录

1. 点击底部导航栏的 **"📋 历史"** 按钮
2. 查看最近发送的消息列表（按时间倒序）
3. 可通过顶部下拉框筛选特定班级
4. 每条消息显示：班级、时间、展示方式、时长等信息
5. 点击 **"重发"** 按钮可一键重新发送该消息

### 3.7 自定义模板

教师可以管理自己的常用语模板，发送消息时一键填入：

1. 点击底部导航栏的 **"📝 模板"** 进入模板管理页
2. **添加模板**：在输入框中输入常用语内容，点击"添加"
3. **编辑模板**：点击模板卡片上的 ✏️ 编辑按钮，修改内容后保存
4. **删除模板**：点击模板卡片上的 🗑️ 删除按钮
5. 模板按自定义排序显示在主页面发送区域

> **提示**：模板持久化存储在后端，换设备登录也能看到。

### 3.8 定时播报

教师可以预设定时或周期性消息，系统自动按时发送：

1. 点击底部导航栏的 **"⏰ 定时"** 进入定时播报页
2. 点击 **"新建定时任务"**
3. 选择目标班级、输入消息内容
4. 选择定时类型：
   - **单次**：指定日期时间发送一次（如"明天上午 9 点通知"）
   - **每日**：每天固定时间发送（如"每天放学前安全提示"）
   - **每周**：每周固定时间发送（如"每周一升旗仪式提醒"）
5. 点击"创建"保存任务
6. 任务列表可查看、启用/禁用、删除

> **注意**：定时任务由后端调度器执行，需保持后端服务运行。

### 3.9 退出登录

点击主页面右上角的 **"退出"** 按钮即可清除登录状态。

## 四、大屏端安装与初始化

### 4.1 获取安装包

大屏端提供两种安装形式：

| 形式 | 文件名 | 说明 |
|------|--------|------|
| **NSIS 安装包** | `Classroom-Horn-Setup-x.x.x.exe` | 标准安装程序，推荐日常使用 |
| **便携版** | `Classroom-Horn-Portable-x.x.x.exe` | 免安装单文件，适合 U 盘部署 |

安装包由 IT 管理员从构建系统获取，或从项目发布页面下载。

### 4.2 系统要求

| 项目 | 最低要求 |
|------|----------|
| 操作系统 | Windows 10 及以上（64 位） |
| 内存 | 2 GB 以上可用 |
| 磁盘空间 | 500 MB |
| 网络 | 局域网连接（有线/无线均可） |
| 显示 | 分辨率 1280×720 以上 |

### 4.3 安装步骤

**安装包模式**：

1. 双击 `Classroom-Horn-Setup-x.x.x.exe`
2. 选择安装路径（默认 `C:\Program Files\classroom-horn\`）
3. 等待安装完成
4. 桌面会自动创建快捷方式

**便携版模式**：

1. 将 `Classroom-Horn-Portable-x.x.x.exe` 复制到目标目录
2. 双击运行即可，无需安装

### 4.4 首次启动配置

1. **启动应用**：双击桌面快捷方式或可执行文件
2. **输入配对码**：
   - 应用启动后显示配对码输入界面（普通窗口模式，非全屏）
   - 输入管理员分配的 **6 位班级配对码**
   - 点击“连接”
3. **连接成功**：
   - 应用自动进入全屏置顶模式（待机界面）
   - 显示班级名称、配对码、当前时间和连接状态
   - 绿色状态点表示已连接，等待教师发送消息

> **提示**：配对码只需配置一次，后续启动会自动连接。如需更换班级，按 `Esc` 键退出全屏回到配对模式重新配置。

### 4.5 开机自启设置

推荐将大屏端设为开机自启，确保教室大屏随时待命：

**方法一：启动文件夹**

1. 按 `Win + R`，输入 `shell:startup`，回车
2. 将大屏端快捷方式复制到此文件夹

**方法二：任务计划程序**（高级）

1. 打开“任务计划程序”
2. 创建基本任务 → 触发器选“登录时”
3. 操作选“启动程序”，指向大屏端可执行文件

### 4.6 日常使用注意事项

- **不要关闭应用**：大屏端需保持运行状态，关闭后将无法接收消息
- **网络要求**：确保教室电脑与办公室后端在同一局域网
- **音量设置**：如需语音播报，请确保系统音量未静音
- **全屏显示**：应用默认全屏运行，按 `F11` 可切换窗口模式
- **自动更新**：当前版本不支持自动更新，需手动替换安装包

## 五、管理后台使用指南

### 5.1 访问管理后台

管理后台提供班级管理、消息审计等功能，在浏览器中打开：

```
http://<办公室电脑IP>:18800/static/admin/
```

### 5.2 班级管理

1. **查看班级列表**：页面加载后自动显示所有班级及其配对码
2. **创建班级**：输入班级名称，点击“创建班级”
3. **编辑班级**：点击班级卡片上的编辑按钮修改名称
4. **删除班级**：点击班级卡片上的删除按钮（需确认）
5. **换码**：点击“换码”按钮重新生成配对码，旧码立即失效

### 5.3 消息审计

1. 切换到“消息审计”标签页
2. 可按**班级**、**教师**、**时间范围**筛选消息记录
3. 消息列表分页显示，包含发送时间、教师、班级、内容等信息

### 5.4 配对码打印

1. 点击 **“📋 打印配对码清单”** 按钮
2. 系统在新窗口生成包含所有班级配对码的可打印表格
3. 使用浏览器打印功能（Ctrl+P）打印纸质清单

### 5.5 消息导出

1. 在消息审计页面点击 **“📥 导出 CSV”** 按钮
2. 系统根据当前筛选条件导出 CSV 文件（UTF-8 BOM 编码）
3. 文件可直接用 Excel 打开，不会出现中文乱码

## 六、班级管理

### 6.1 概述

教师端内置「班级管理」功能，教师可自主创建、编辑、删除班级，无需管理员介入。系统为每个班级自动生成唯一的 6 位数字配对码，用于大屏端连接。

**核心流程**：

```
教师创建班级 → 系统自动生成配对码 → 教师将配对码告知 IT/大屏端 → 大屏端输入配对码连接
```

### 6.2 创建班级

1. 点击底部导航栏的 **“🏫 班级”** 进入班级管理页
2. 在顶部输入框中输入班级名称（如“二年级A班”）
3. 点击 **“+ 创建”** 按钮
4. 系统自动生成 6 位配对码，创建成功后显示配对码
5. 点击 **“复制”** 按钮可一键复制配对码

> **提示**：创建成功后请立即复制配对码，告知 IT 管理员或在大屏端输入。

### 6.3 查看与复制配对码

班级列表中以大字体醒目展示每个班级的配对码：

- **📋 复制**：一键复制配对码到剪贴板，方便通过微信、纸质等方式分发
- **🔄 换码**：重新生成配对码（旧码立即失效，已连接的大屏端需重新配置）

### 6.4 编辑班级名称

1. 点击班级卡片右上角的 ✏️ 编辑按钮
2. 修改班级名称
3. 点击“保存”确认或“取消”放弃

### 6.5 删除班级

1. 点击班级卡片右上角的 🗑️ 删除按钮
2. 确认删除提示（删除后不可恢复，相关消息记录也会被清除）
3. 点击“确认删除”

### 6.6 配对码分配建议

| 场景 | 建议做法 |
|------|----------|
| 单机单教室 | 教师创建班级后，直接在大屏端输入配对码 |
| 多教室集中管理 | 教师创建班级后，将配对码清单通过微信/纸质分发给各教室 IT |
| 配对码泄露风险 | 使用“换码”功能重新生成，旧码立即失效 |

## 八、常见问题与故障排查

### 教师端问题

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| **页面打不开** | 后端未启动 / IP 错误 | 确认后端服务正在运行；检查 IP 地址和端口 |
| **登录失败** | 姓名格式问题 | 确认输入了有效姓名（不能为空）；首次登录会自动注册 |
| **发送失败** | 网络断开 / Token 过期 | 检查网络连接；刷新页面重新登录 |
| **登录状态丢失** | 浏览器清除了缓存 | 重新输入姓名登录 |
| **图片上传失败** | 图片过大或格式不支持 | 确认图片 ≤5MB，格式为 JPG/PNG/GIF/WebP |
| **撤回失败** | 超过 60 秒时限 | 消息发送超过 60 秒后无法撤回 |
| **定时任务未执行** | 后端服务未运行 | 定时任务需后端持续运行；检查后端日志 |
| **界面显示异常** | 浏览器版本过低 | 使用 Chrome / Edge / Safari 最新版 |

### 大屏端问题

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| **连不上后端** | 后端未启动 / 端口被占用 | 检查后端进程是否运行；查看 `logs/backend.log` |
| **消息不显示** | 网络连接中断 | 查看状态指示器；应用会自动重连，等待 30 秒 |
| **语音不播报** | 系统静音 / 浏览器不支持 | 检查系统音量；确认 Windows TTS 引擎可用 |
| **配对码输入后无反应** | 网络不通 / 配对码错误 | 检查网络连接；确认配对码正确 |
| **应用黑屏/白屏** | 渲染异常 | 按 `Ctrl+Shift+R` 刷新；或重启应用 |
| **消息显示不完整** | 内容超出显示区域 | 减少单条消息字数（建议 200 字以内） |

### 后端问题

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| **启动失败** | 运行环境损坏 | 重新解压后端发布包覆盖安装 |
| **数据库锁定** | 并发写入冲突 | 重启后端服务 |
| **端口被占用** | 18800 端口被其他程序使用 | 修改 `data/settings.json` 中的端口配置 |
| **日志位置** | 需要排查问题 | `logs/backend.log` |

### 快速恢复步骤

如果系统出现异常，按以下顺序排查：

1. **检查后端**：确认后端进程正在运行（任务管理器中查找 `python.exe`）
2. **检查网络**：在办公室电脑浏览器中访问 `http://<后端IP>:18800/health`，应返回 JSON
3. **重启大屏端**：关闭大屏端应用，等待 5 秒后重新启动
4. **重新配对**：在大屏端清除数据后重新输入配对码
5. **查看日志**：检查 `logs/backend.log` 获取详细错误信息
